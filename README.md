# Design-and-Manufacture-of-Compact-Constant-Temperature-Water-Heaters
Responsible for the design and prototyping of a control system based on the STM32F103C8T6, including component selection and the integration of temperature sensing, button interaction, an OLED display, and heating and cooling modules.

## My Responsibilities
- Led the system design and component selection for an STM32-based water temperature control prototype.
- Developed the embedded control software and designed the schematic and two-layer PCB.
- Completed hardware assembly, firmware programming and system testing.

## Work Completed
- Developed modular C code in Keil for DS18B20 temperature sensing, OLED display, button input, and temperature threshold settings.
- Verified mode switching and heating/cooling control logic through Proteus simulation.
- Designed the PCB in Altium Designer and completed component soldering and peripheral connections.
- Integrated a relay-controlled heater and cooling fan, then tested temperature monitoring, threshold adjustment, and heating/cooling operation on the physical prototype.
