# Design-and-Manufacture-of-Compact-Constant-Temperature-Water-Heaters
Responsible for the design and prototyping of a control system based on the STM32F103C8T6, including component selection and the integration of temperature sensing, button interaction, an OLED display, and heating and cooling modules.
